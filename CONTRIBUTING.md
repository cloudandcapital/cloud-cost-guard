# Contributing

Contributions are welcome. Please open an issue before submitting a pull request so the change can be discussed first. Keep pull requests focused — one feature or fix per PR. Python changes should pass the repository's unittest suite (`python -m unittest discover -s tests -p 'test_*.py' -v`) and follow the existing code style. For new features, include a test that covers the core behavior. For bug fixes, add a regression test if one does not already exist. By submitting a pull request you agree to license your contribution under the project's MIT License.
